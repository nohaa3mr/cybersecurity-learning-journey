# Blue Team Investigation Chains

**Core question:** Who → What → Where → When → How → Is it normal?

| Domain | Chain |
|--------|-------|
| Network | Source → Protocol → Destination → Route → Segment → Expected? |
| Windows | User → Process → File → Service → Registry → Event Log → Network |
| Linux | User → Command → Process → File → Permission → Service → Network → Logs |
| Protocols | Who → Protocol → Port → Request → Expected? → Evidence |
| SIEM alert | Understand → Validate → Correlate → Investigate → Verdict → Respond |

The goal isn't memorizing commands. It's knowing what **normal** looks like so you can spot what doesn't fit.
